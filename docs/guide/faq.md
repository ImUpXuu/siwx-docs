# 常见问题

::: tip 通用排查三步
1. **先升级到最新版本**——历史上多数"检测不到/秒退/密钥 0/N"的问题都已在后续版本修复（见下方对应条目）；
2. 看 Web 控制台「日志」页或 `logs/siwx.log` 的报错；
3. 仍解决不了：用「设置 → 环境信息」复制打码后的环境信息（或 `python run.py doctor`），按 issue 模板反馈。
:::

## 安装与启动

**Q：Windows 上提示"未找到微信数据目录"或引导无法下一步？**

先升级到最新版本——旧版本只探测默认存储路径，微信数据目录迁移到自定义位置时检测不到，该问题已修复。仍不行时依次检查：微信是否在本机安装并登录过、数据目录是否存在、是否被安全软件拦截，然后带环境信息提 issue。

**Q：macOS 双击打开应用秒退，日志报 `OSError: [Errno 30] Read-only file system`？**

旧版本把数据写在了应用安装目录里，macOS 双击启动时该位置只读导致初始化失败。**v5.0.2 起**数据目录已迁移到 `~/Library/Application Support/stories-in-wx/`，升级到最新版即可。

**Q：被杀毒软件拦截 / 误报怎么办？**

解密与跨进程读取涉及敏感操作，部分安全软件会告警。将程序加入信任列表后重试；如仍异常，看「日志」页的具体报错。

## 密钥与解密

**Q：为什么必须在本机运行？**

微信数据库、密钥和聊天记录都是高度敏感的个人数据。SIWX 设计为本地运行，核心流程不需要把数据上传到任何第三方服务器，Web 控制台只绑定 `127.0.0.1`。

**Q：密钥提取一直 0/N 怎么办？**

- **macOS**：升级到最新版本（旧版本存在 LLDB 脚本加载失败的缺陷，表现为日志里 `error: module importing failed`，此时重新登录微信也无效）；密钥未缓存时，点击"提取并解密"后 **60 秒内重新登录微信**。仍失败时把日志中 `[macos_lldb]` 段落附到 issue。
- **Windows**：确认微信正在运行或刚登录过 → 确认选对了账号 → 数据目录完整 → 未被安全软件拦截 → 尝试「设置 → 清除缓存」后重新提取。

**Q：解密失败怎么办？**

依次检查：微信是否正在运行 / 是否刚重新登录过 → 是否选中了正确的账号 → 数据目录是否完整 → 是否被安全软件拦截 →（macOS）是否允许 LLDB 调试且微信版本满足要求。然后打开 Web 控制台的"日志"页面看详细错误。

**Q：升级后需要重新解密吗？**

不需要。解密产物按 `mtime + size + key` 命中缓存，源库未变时直接复用，重跑秒回。

**Q：换电脑后密钥库能迁移吗？**

不建议。Windows 下密钥库经 DPAPI 加密、绑定本机用户，拷到其他机器无法解密。新机器上重新提取一次即可；`output/` 解密产物与导出文件本身可以直接拷贝使用。

## 浏览与导出

**Q：HTML 导出能离线打开吗？**

可以。HTML 导出面向归档场景；若同时导出媒体，请保留导出目录结构或使用 ZIP 包，避免资源路径丢失。

**Q：语音能导出成 MP3 吗？**

当前默认输出 **WAV**（pilk 解 SILK → PCM → 标准库封装），WAV 是无损 PCM 容器，通用播放器和剪辑软件都支持。MP3 属于有损压缩，需要额外编码器，暂未内置。

**Q：会不会占用大量 CPU / 磁盘？**

解密是短时高吞吐但可控的任务；媒体按需解密；缓存可随时在设置页清除。全自动增量刷新默认关闭，开启后也可自行调间隔。

## 朋友圈

**Q：为什么朋友圈有些图片加载不出来？**

绝大多数是**微信 CDN 侧已经删除了原图**。实测自己发布的图片约 58% 返回 HTTP 404，好友发布的约 4%。这类图片在微信里点开同样看不到，程序只能如实报错（失败原因会写进日志页，导出报告里也有分布统计）。少量情况是视频链接短时失效（`encfilekey` 过期后返回 400）。详见[朋友圈 → 已知边界](/guide/sns#已知边界-如实说明)。

**Q：朋友圈需要单独解密吗？**

不需要。执行"提取并解密"时会连 `sns.db` 一起处理，产物落在 `output/<账号>/sns/sns.db`。如果左侧菜单里没有「朋友圈」页，说明该账号的数据目录下没有 `sns.db`。

**Q：朋友圈的图片能用聊天图片的方式解开吗？**

不能。两者是**完全独立的两套加密体系**：聊天图片是 AES-ECB + XOR（账号级密钥，从 MMKV 离线派生，读本地缓存）；朋友圈图片是 ISAAC64 流密码（每图独立密钥，写在动态 XML 里，从 CDN 下载）。代码里也是两个独立模块，互不通用。

**Q：朋友圈能像聊天一样让 AI 检索吗？**

可以。MCP 提供 `list_sns_accounts` / `get_sns_timeline` / `get_sns_detail` / `get_sns_friends` / `export_sns` 五个朋友圈工具，AI 可直接浏览、搜索、过滤和导出朋友圈（时间线只回互动计数与正文，完整评论在详情里；CDN 媒体 URL 不暴露给 AI）。也可以先导出为 JSON / Markdown 再交给 AI。详见 [MCP 接入](/guide/mcp)。
