# Web 控制台

启动程序后（双击 exe 或 `python run.py serve`），浏览器自动打开 `http://127.0.0.1:8787`。控制台只监听本机回环地址，外部设备无法访问。

## 引导流程

首次使用按引导页完成：欢迎检查 → 选择账号 → 提取并解密。引导可随时从「引导设置」页重新运行。

## 功能页面

左侧菜单共 8 个页面，与界面顺序一致：

| 页面 | 说明 |
| --- | --- |
| 🧭 引导设置 | 首次使用的分步引导，可随时重新运行 |
| 💬 聊天查看 | 浏览会话列表，分页查看消息，预览图片、表情、头像、语音，支持复制与多选 |
| 🌐 朋友圈 | 浏览解密后的朋友圈动态，搜索、筛选发布者，查看图片/视频/实况照片，导出（详见[朋友圈](/guide/sns)） |
| 📊 聊天统计 | 总消息量、类型分布、月度趋势、活跃度与私聊发送者排行 |
| 📦 导出 | 多选会话批量导出，勾选是否导出媒体 / 语音，可打包 ZIP（详见[导出](/guide/export)） |
| 🔌 MCP | 生成 AI 客户端接入配置，管理各工具开关，查看调用日志（详见 [MCP 接入](/guide/mcp)） |
| 📋 日志 | 查看任务进度、错误栈、运行日志，支持脱敏导出 |
| ⚙️ 设置 | 版本更新、日志模式、**环境信息**、缓存状态、**自动刷新数据库**、清除缓存 |

侧栏还有两个常驻入口：**⚖ 免责声明**（随时重看）与 **☾ 主题切换**（明暗主题）。首次启动会强制确认一次免责声明。

> 若安装了[插件](/plugin-development)，插件页会排在上述内置页面之后，样式与高亮完全一致。

## 聊天查看

- 会话列表支持搜索；消息区分页加载，可按时间轴快速跳转。
- 图片、表情、头像按需解密（本地资源库 LRU 缓存）；未下载原图的图片提供"在微信中打开后重试"入口。
- 语音在线转码播放；引用消息（回复）会显示被引用的原文。
- 支持多选消息后一键复制。

## 聊天统计

总消息量、类型分布、月度趋势、活跃度与私聊发送者排行，跨分片聚合，秒级出结果。

## 日志与排查

- 「日志」页展示任务进度与错误栈，支持**脱敏导出**（敏感字段自动打码）。
- 「设置 → 环境信息」生成打码后的环境信息（路径中的用户名已打码），提 issue 时直接粘贴。
- 遇到问题先看[常见问题](/guide/faq)。
